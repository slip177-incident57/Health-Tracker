Import Apple Health

No Mac or coding needed. On your iPhone, open Health → profile picture → Export All Health Data, then save the export to Files. Select that ZIP here, or unzip it in Files and select export.xml.

This is a manual import, not automatic syncing. Processing stays on this device. Only sleep and cardio values are saved.

Sleep counts asleep stages only, with overlapping records counted once. A noon-to-noon window assigns the previous night's sleep to the waking day (and includes naps in that window). Cardio counts recorded walking, running, cycling, swimming, elliptical, rowing, stairs, hiking, dance, HIIT, jump rope, kickboxing, cross-country skiing, and hand cycling workouts. It uses elapsed workout time, including any pauses; everyday movement and strength sessions are excluded. Overlaps count once. Dates use this device's time zone.
